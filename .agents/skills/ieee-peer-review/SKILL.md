# ieee-peer-review

Read the manuscript, verified results, closest cards and protocol; never read
author reasoning. Check every contribution against data, uncertainty and tested
settings. Flag unsupported numerical gains and extrapolation as major. Check
baseline fairness, equations, limitations, citations, originality, figures and
reproducibility. Return location-grounded severity findings and fixes. A clean
control may have no findings. Never approve a PI gate or claim journal acceptance.
