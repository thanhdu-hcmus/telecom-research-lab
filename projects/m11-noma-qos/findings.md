# Findings

## Current understanding

The plan specifies an established two-user NOMA benchmark for M11. A proposed
scope and synthetic profile have been prepared for G1. No P2 literature review,
approved model, protocol, simulation or manuscript exists for this project.

## Supported claims

None from this project. The conditional NOMA comparison is a proposed acceptance
expectation to derive and verify later, not an experimental result.

## Lessons and constraints

Keep resource budgets, scheduling, QoS and feasibility reporting explicit.
Dry-run mode permits established-method cards without relabelling them novel.
Scientific gate approvals and report usability ratings belong to the PI.

## Open questions

- Are the gate reports usable? Record the PI's actual rating at each gate.
- Which reference paper should be used for M12 after M11 is accepted?
